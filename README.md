# 🔢 MatrixLib

A small educational linear algebra library written in C++.

MatrixLib was originally created as a university assignment for an algorithms and programming languages course. The project was focused on practicing C++ templates, inheritance, operator overloading and basic multithreading.

## ✨ Features

- generic `Matrix<T>` and `Vector<T>` types;
- basic matrix and vector operations;
- matrix addition and subtraction;
- scalar multiplication;
- matrix multiplication;
- matrix-vector operations;
- matrix transposition;
- basic multithreaded matrix multiplication;
- custom exception handling.

## 🛠️ Tech

- C++
- STL
- Templates
- `std::thread`

## 🎯 Project Purpose

The project is primarily educational and represents one of my earlier C++ projects.

I plan to gradually revisit it, improve code quality, portability, documentation and project structure while keeping its original educational purpose.

## 📌 Status

The library is functional as an educational project, but it is **not intended to compete with production linear algebra libraries** such as Eigen.

Further cleanup and modernization are planned.
